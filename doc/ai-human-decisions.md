1. **공개 웹사이트 열기**:
   - 브라우저에서 `index.html`을 직접 열거나 GitHub Pages(`https://gksxogksxo1001-sketch.github.io/project12/`)에 접속합니다.
   - 첫 화면의 이름('주한태')과 날짜 포함 한 줄 소개, 4대 진입 입구(이야기·숫자·대표작·이력서)를 확인합니다.
   - 이야기 본편이 토막마다 날짜(2022-03, 2022-12, 2026-08-11, 2026-10-13, 2026-10-20)로 시작하는지 확인합니다.
   - 숫자 섹션에서 3대 출처(내 출석 기록, 리추얼 기록, 내 제출 현황)와 고난 짝지음을 확인합니다.
   - 대표작에서 10번 논문(로그인 없이 새 창에서 바로 열림)과 13번 앱 예정일(2026-11-13)을 확인합니다.
2. **장치(Generator) 1초 재현 실행**:
   ```bash
   node generator/engine.js
   ```
   - 콘솔에 40일 통계가 출력되고 `site-data.json`, `site-data.js`, `doc/generated-narrative-candidates.md`가 갱신됩니다.
3. **새 폴더 2회 동일 결과 검증 (체크리스트)**:
   ```bash
   node generator/verify-reproducibility.js
   ```
   - 새 임시 폴더에서 2회 독립 실행 후 산출물 SHA-256 해시가 100% 일치함을 확인합니다.

## 💡 AI와 나의 판단 세 줄

1. **[BRA-C03/C04 날짜 장면과 시스템 통제]** 형용사형 미사여구를 배제하고, "2026년 10월 14일 이틀 연속 지각 앞에서 자책 대신 열 개의 알람을 맞춰 30분 먼저 강의실의 불을 켜는 사람"으로 한 줄 소개를 정의하고 이야기 토막마다 날짜가 있는 구체적 장면으로 시작하기로 결정했습니다.
2. **[BRA-C05 정직한 3대 출처와 고난 짝지음]** 숫자를 과장하지 않고 '내 출석 기록(지각 2회/출석률 96%)', '리추얼 기록(40일/아침 100%)', '내 제출 현황(11개 과제 100%)' 3대 출처로 엄밀히 분리하고, 지각 위기를 알람 10개 및 30분 조기 도착과 정확히 짝지어 신뢰성을 입증하기로 판단했습니다.
3. **[BRA-C06 로그인 없는 대표작과 지속 갱신 장치]** 외부 링크의 로그인 장벽을 없애기 위해 10번 논문 전문 웹 뷰어를 사이트 내 직접 호스팅하고 13번 앱 예정일(2026-11-13)을 명시하며, 새 폴더 2회 실행 결과가 100% 일치하는 결정론적 생성 엔진을 독립 패키징하기로 합의했습니다.
