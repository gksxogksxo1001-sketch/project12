## 🎯 과제 개요
처음 온 사람이 3분 안에 읽고 이 사람과 일하고 싶어지는 공개 사이트입니다.  
첫 화면에는 내 이름과 한 줄 소개, 그리고 **이야기·숫자·대표작·이력서로 들어가는 4대 입구만** 둡니다.  
소설의 각색을 사실로 되돌린 1,514자 자기소개 본편은 **모든 토막이 날짜가 있는 장면으로 시작**하며, **자기조절력 · 대인관계력 · 자기동기력** 세 능력을 드러냅니다.  
회복탄력성과 과제지속력은 **「내 출석 기록」, 「리추얼 기록」, 「내 제출 현황」 3대 출처의 숫자**로 뒷받침하고 지각 고난과 짝지었습니다.

## ⚙️ 장치 돌리는 방법 3단계 (새 임시 폴더 실행 보장 · BRA-C09)

과정이 끝난 뒤에도 새 기록을 넣고 한 번 돌리면 사이트의 숫자와 문단 후보가 새로워집니다.

```bash
# [1단계] 새 입력 데이터 배치
# inputs/ 폴더에 새로운 ritual-history-*.txt, attendance.json, task-list.json을 넣습니다.

# [2단계] 장치 실행 및 사이트 데이터/문단 후보 갱신
node generator/engine.js

# [3단계] 새 임시 폴더 2회 독립 실행 및 결정론적 재현성 검증
node generator/verify-reproducibility.js
```

## 💡 AI와 나의 판단 보고서 (BRA-C12)

### ① AI에게 맡긴 일
- 40일간의 리추얼 텍스트 파싱, 호흡 시간 집계, 아침/저녁 완수율 계산 등 정규표현식 기반의 정량적 데이터 가공.
- 반응형 웹 레이아웃, 다크/라이트 테마 제어, SHA-256 해시 검증 스크립트 작성 등 기계적 코드 스캐폴딩.

### ② 내가 직접 판단한 일
- 11번 소설의 문학적 각색을 걷어내고 10월 13~14일 지각 사건과 알람 10개 설정을 솔직하게 서술한 1,514자 본편 작성.
- 한 줄 소개 3가지 후보 중 실제 위기 날짜와 시스템 통제가 들어간 문장을 최종 선택한 일.
- 경력기술서를 과제 하나당 한 줄 포맷으로 작성하고 세 능력에 고르게 배분한 일.
- 10번 논문 웹 뷰어를 사이트 내 직접 호스팅하여 시크릿 창 로그인 장벽을 없앤 일.

### ③ AI 제안을 따르지 않은 일 (이유 포함)
- **AI의 초기 제안**: 포트폴리오를 화려하게 꾸미기 위해 "완벽한 개발자" 등의 미사여구와 과장된 형용사 표현을 제안함.
- **따르지 않은 이유**: 본 과제의 본질은 "자랑이 아닌 고난을 먼저 쓰고 바꾼 행동을 보여주는 것"이며, "작은 숫자를 있는 그대로 쓰는 것이 부풀린 기록보다 믿음직하다"는 원칙을 지키기 위해 AI의 미사여구를 전면 배제하고 사실 기반의 담백한 시스템 서사로 직접 교정함.
